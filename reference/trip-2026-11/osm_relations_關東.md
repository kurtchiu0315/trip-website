# 關東路線 OSM route relation 筆記

查詢日期：2026-11-07。方法：Overpass（bbox 限縮）找候選，再用 OSM API `relation/<id>/full` 確認站序。
站名一律是 OSM 原文（不含「駅」）。站序為 relation 成員中 stop／platform 的順序。
