## 日本遊客熱線

日本國家旅遊局(JNTO)設立了一條遊客熱線，提供全年無休的全天候服務。如果發生事故或緊急情況，請來電熱線諮詢旅遊資訊或尋求協助。遊客熱線提供您英文、中文和韓語和的服務

| 電話服務中心訊息 |  |
| --- | --- |
| 服務名稱 | 遊日旅客熱線 |
| 電話號碼 | 050-3816-2787 |
| 撥自海外 | +81-50-3816-2787 |
| 服務時間 | 全年365天，每天24小時 |
| 對應語言 | 英語、中文、韓語 |
| 服務範圍 | 緊急情況（意外、疾病等）或自然災害時的支援及協助，以及一般旅遊資訊 |

## 實用電話號碼

多數機構都有懂英語的人員：

| 緊急情況 |  |  |
| --- | --- | --- |
| 警察 | 緊急 | 110 |
|  | 失物認領 | 0570-550-142 |
|  | 一般資訊 | (03) 3503-8484（英語及其他幾種外語） |
| 消防/救護車 | 緊急 | 119 |
